## 1) MVP-3B2 — выполнено и закрыто (уровень “Финал — железобетон”)

### Блок 1: Вложения — Variant B (pending до Save)
- Вложения можно добавлять до сохранения записи (pending-state).
- Нет “просачивания” вложений при Cancel/Lock/Restore.
- Нет plaintext; безопасная модель.
- Нет потерь/наездов UI по вложениям.

### Блок 2: Orphan cleanup и edge-cases по вложениям
- Диагностические логи:
  - `ATT_ORPHAN_CLEANUP_BEGIN → (SKIP | END | ERROR)`
  - `ATT_ORPHAN_CLEANUP_ERROR` (trigger/force/phase/tag/ex и т.п.)
- Edge-cases: meta/blob mismatch, dangling refs, защита от ложных переносов/пуржа.
- Отчёт `orphan_cleanup_report.txt` без путей.
- Backup/restore verify: dangling meta не блокирует.
- Self-heal dangling attachment meta: Unlock + rate-limit + перед BackupNow/RestoreBackup.
- Корзина по вложениям: restore не удаляет; delete forever удаляет корректно.

### Блок 3: Smoke и инварианты
- Не сломаны: multi-select / Ctrl+A / Del / drag&drop / трей.
- UX-инвариант: клик в пустоту снимает выделение, **правый контекст не сбрасывается**.
- Не вводился режим “все записи”.
