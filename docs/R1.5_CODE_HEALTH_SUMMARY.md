# R1.5 — Code Health перед установщиком (summary)

Дата фиксации: 2026-02-24

Цель ветки R1.5: снизить риск регрессий/крашей и упростить поддержку кода перед первым установщиком.

## Что сделано (по архивам)

- **R1.5.1 (`..._212`)** — добавлен `docs/TECH_DEBT.md` (инвентаризация P0/P1/P2: где, риск, что делать, как проверить).
- **R1.5.2 (`..._213`)** — safe cleanup:
  - убраны очевидные дубли/копипаста (в зоне toast генератора);
  - null-safe правки по `Grid` для сценариев Lock и restore по double-click;
  - минимальная диагностика вместо части silent `catch {}` в критичных IO ветках.
- **R1.5.3.1 (`..._214`)** — `SettingsStore`:
  - атомарный Save (`settings.json.tmp → replace/move`) + `settings.json.bak`;
  - fallback Load на `.bak` и auto-heal;
  - диагностические теги `SETTINGS_*`.
- **R1.5.3.2 (`..._215`)** — `VaultIoGate`:
  - slow-wait логирование через `DiagnosticsLog.AppendLine("IO_GATE_WAIT", ...)`.
- **R1.5.3.3 (`..._216`)** — унификация toast:
  - `SettingsWindow` + `PasswordGeneratorWindow` переведены на `PopupToastController`.
- **R1.5.4 (`..._217`)** — полировка:
  - `DiagnosticsLog` пишет UTF-8;
  - устранена путаница по `AUDIT.md` (в корне оставлен redirect на `docs/AUDIT.md`);
  - актуализированы `docs/STATUS.md` и `docs/CHANGELOG.md`.

## Что осталось (по TECH_DEBT)

В `docs/TECH_DEBT.md` остаются пункты, которые сознательно **не делали** в R1.5 (чтобы не повышать риск):

- **TD-005** — расширить диагностику вместо silent `catch {}` в других критичных местах (backup/restore/IO), но дозировано (без спама).
- **TD-007 / TD-008** — частичная унификация selection-логики MainWindow и дальнейшее снижение nullable-шумов в зоне `Grid` (лучше отдельным подблоком, с регресс-чеклистом).
- **TD-011** — инвентаризация `MessageBox.Show` и перевод части “инфо” сообщений на toast (где это уместно), без ломания подтверждений.
- **TD-014** — распил `MainWindow.xaml.cs` на partial по темам (полезно, но косметика поддержки).

## Рекомендованный следующий шаг

Если текущие правки проверены на твоей Windows-сборке и регресс-чеклист пройден — можно переходить к установщику (**Inno Setup, вариант A**).
