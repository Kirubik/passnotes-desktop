# PassNotes Desktop help

This help is meant to explain the real, working PassNotes Desktop functionality in a practical way.
It separates confirmed current features from ideas that may appear later.

> Open help: **F1** or **Menu -> Help**.

## Current features

- [User manual](./manual.md) — how the main window works and how to use the main features day to day.
- [Vaults, backups, and another vault](./vaults-and-backups.md) — where the vault lives, how backups work, and how to switch to another vault file.
- [Restore and common errors](./recovery.md) — what to do if the vault cannot be opened or restore fails.
- [FAQ / quick guide](./faq.md) — short answers without reading the full manual first.
- [About](./about.md) — short information about the app.
- [Hotkeys](./hotkeys.md) — currently working hotkeys.

## What may appear later

- [What may appear later](./future.md) — a separate list of possible development directions without promised dates.

## Where to start

1. If you are new to the app, open the [User manual](./manual.md).
2. If you want to understand how to keep data safe, then open [Vaults, backups, and another vault](./vaults-and-backups.md).
3. If you need a short answer first, open [FAQ / quick guide](./faq.md).
4. If you want to see what already works versus what is only a future idea, open [What may appear later](./future.md).
