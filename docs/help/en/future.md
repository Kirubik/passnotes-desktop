# What may appear later

This page collects ideas and possible development directions for PassNotes Desktop.

Important:

- this is **not** a list of already finished features;
- this is **not** a promise of dates;
- priorities may change;
- new functionality may appear only if the app keeps developing and those ideas prove useful to users.

## Possible directions

### Excel import and export

In the future, the app may get a more convenient Excel-based way to exchange data for some transfer and viewing scenarios.

### More themes

The theme set may continue to grow if there is clear demand for additional light and dark variants.

### Broader functionality

Over time, the app may receive additional convenience features and more flexible user workflows.

### A more note-friendly mode

PassNotes already stores not only passwords but also notes and comments.
In the future, this scenario may be developed further for users who want a more convenient note-oriented workflow, not only password storage.

## How to read this list

If users like the app and development continues, some of these ideas may eventually become real features.
For now, they are only development directions, not current functionality.
