# Руководство пользователя

PassNotes Desktop — локальное приложение для хранения паролей, заметок, комментариев и вложений в зашифрованном хранилище.
Ниже описан только тот функционал, который уже работает сейчас.

> Справка открывается по **F1** или через **Меню -> Справка**.  
> Список горячих клавиш: [Горячие клавиши](./hotkeys.md).

---

## Быстрый старт

1. Разблокируйте приложение или откройте свой vault.
2. Выберите слева папку, раздел **Избранное**, **Корзина** или **Без папки**.
3. Нажмите **+** над таблицей записей, чтобы создать запись.
4. Заполните основные поля и нажмите **Сохранить**.
5. Для быстрого доступа используйте поиск, избранное, копирование логина/пароля и контекстные меню.

---

## Как устроено главное окно

### Верхняя панель

- **Меню** — настройки, справка, импорт, экспорт, бэкапы, блокировка и выход.
- **Поиск записей** — ищет записи в правой таблице. Если рядом показан контекстный блок, вы видите, какая папка или какой специальный раздел сейчас выбраны. Кнопка **x** очищает запрос.
- **Кнопки справа от поиска** — добавить, изменить, удалить запись, скопировать логин, скопировать пароль.
- **Генератор паролей** — открывается отдельной кнопкой на верхней панели.
- **Высота строк** — ползунок меняет высоту строк в таблице записей.

### Левая часть окна

- **Поиск папок** — помогает быстро найти нужную папку.
- **Избранное** — показывает записи, отмеченные звездочкой.
- **Корзина** — показывает удаленные записи.
- **Без папки** — показывает записи, которые не привязаны к обычной папке.
- **Обычные папки** — основная структура для записей.

### Правая часть окна

- **Таблица записей** показывает записи для текущего контекста.
- **Двойной клик по записи** открывает редактирование.
- Для множественного выбора используйте **Ctrl** и **Shift**.
- Простая протяжка мышью по строкам больше не расширяет выделение — это нормальное текущее поведение.
- Внизу окна есть строка состояния: текущий контекст, число записей и число выбранных записей.

---

## Работа с папками и контекстом

- Чтобы создать папку, используйте кнопку **+** рядом с поиском папок или ПКМ по дереву папок.
- Через ПКМ по папке доступны действия **создать**, **переименовать** и **удалить**.
- Если вы нашли запись через поиск, можно перейти к ее настоящей папке через ПКМ по записи.
- Рядом с поиском записей может показываться небольшой контекстный блок с текущей папкой или специальным разделом.
- Крестик на этом блоке сбрасывает текущий контекст.
- Если контекст сброшен и вы вводите поисковый запрос, поиск идет по всем записям сразу.
- Если контекст сброшен и запрос пустой, список записей может быть пустым. Это нормальное поведение.

---

## Что означают основные термины

- **Контекст** — раздел, в котором вы сейчас работаете: обычная папка, **Избранное**, **Корзина** или **Без папки**. Он определяет, какие записи показывает правая таблица.
- **Контекстный блок** (`chip`) — небольшой блок рядом с поиском записей. Он показывает текущий контекст и позволяет сбросить его крестиком.
- **Избранное** — специальный раздел со записями, которые отмечены звездочкой.
- **Корзина** — специальный раздел с удаленными записями. Отсюда запись можно восстановить или удалить навсегда.
- **Без папки** — раздел для записей, которые не привязаны к обычной папке.
- **ПКМ** — правый клик мышью. В PassNotes через ПКМ часто открываются важные действия с папками, записями и полями.

---

## Работа с записями

- **Создать запись** — кнопка **+** над таблицей или ПКМ по таблице.
- **Изменить запись** — двойной клик, кнопка редактирования или ПКМ по записи.
- **Удалить запись** — переносит ее в **Корзину**.
- **Удалить навсегда** и **Восстановить** доступны в контексте **Корзины**.
- **Звездочка** в таблице добавляет или убирает запись из **Избранного**.
- **Копировать логин** и **Копировать пароль** работают для одной выбранной записи.

Нормальное поведение:

- действия с записью могут быть недоступны, если приложение заблокировано;
- часть команд зависит от текущего контекста;
- если выбрано несколько записей, доступны только подходящие для множественного выбора команды.

## Полное окно комментария

Полное окно комментария уже работает и полезно для длинных заметок.

Как открыть:

1. Откройте создание или редактирование записи.
2. Щелкните ПКМ по полю **Комментарий**.
3. Выберите **Открыть комментарий в отдельном окне**.

Что делает это окно:

- открывает большой многострочный редактор комментария;
- удобнее для длинного текста, заметок и списков;
- возвращает текст обратно в форму записи после подтверждения.

Нормальное поведение:

- **ОК** переносит текст обратно в запись;
- **Отмена** закрывает окно без применения изменений из этого большого окна;
- обычный **Enter** вставляет новую строку;
- **Ctrl+Enter** подтверждает комментарий.

## Контекстные меню (ПКМ)

PassNotes активно использует контекстные меню. Это нормальная часть интерфейса.

### ПКМ по таблице записей

Там могут быть доступны:

- добавить запись;
- изменить запись;
- удалить запись;
- восстановить запись или удалить навсегда в **Корзине**;
- добавить в избранное или убрать из избранного;
- перейти к папке записи;
- скопировать логин;
- скопировать пароль;
- включить пункт **Показывать колонку «Обновлено»**.

### ПКМ по дереву папок

Там доступны действия с папками:

- создать;
- переименовать;
- удалить.

### ПКМ по полю комментария

Там доступны:

- вырезать;
- копировать;
- вставить;
- выделить все;
- открыть комментарий в отдельном окне.

### ПКМ по списку вложений

Там доступны:

- открыть вложение;
- сохранить как;
- скопировать имя файла;
- удалить вложение.

Нормальное поведение:

- недоступные команды обычно означают, что сейчас не выбран подходящий объект;
- в заблокированном состоянии часть команд недоступна;
- в поиске и в корзине состав команд может отличаться от обычной папки.

## Отображение времени

Время в списке записей уже поддерживает разные часовые пояса.

Как это работает:

- у записи есть время обновления;
- колонка **Обновлено** по умолчанию скрыта;
- ее можно включить через ПКМ по таблице или по заголовку таблицы;
- в заголовке колонки показывается текущий `UTC`-сдвиг;
- в подсказке к заголовку показывается полное имя часового пояса.

Где настраивается:

- **Настройки -> Общее -> Часовой пояс**.

Нормальное поведение:

- если выбран системный часовой пояс, приложение использует настройки Windows;
- если выбран другой часовой пояс, отображение времени пересчитывается под него;
- смена часового пояса меняет отображение времени, а не содержимое самой записи.

## Смена темы

Смена темы уже встроена в приложение.

Где находится:

- **Настройки -> Общее -> Тема**.

Что доступно сейчас:

- **Стандартная**
- **Шалфейная светлая**
- **Арктическая белая**
- **Полуночно-сланцевая**

Нормальное поведение:

- выбранная тема сохраняется как настройка приложения;
- интерфейс приложения, диалоги и встроенная справка работают в рамках выбранной темы;
- если вы меняете тему, это пользовательская настройка приложения, а не отдельный профиль данных.

## Поиск, избранное и корзина

### Поиск по записям

- верхнее поле поиска фильтрует записи в правой таблице;
- если рядом показан контекстный блок, он показывает, какая папка или какой специальный раздел сейчас выбраны;
- если контекстный блок сбросить крестиком и ввести запрос, поиск идет по всем записям сразу;
- если контекст не выбран и запрос пустой, список записей может быть пустым;
- если вы не помните, где находится запись, проще всего сбросить контекстный блок и ввести запрос;
- запрос можно быстро очистить кнопкой **x**;
- если запись найдена в результатах поиска, через ПКМ по записи можно перейти к ее настоящей папке;
- если поиск активен, часть действий в ПКМ может подстраиваться под режим результатов поиска.

### Поиск по папкам

- помогает быстро найти нужную папку в дереве слева;
- поле поиска по папкам не меняет записи само по себе, а помогает быстрее добраться до нужного контекста.

### Избранное

- запись можно добавить в избранное через звездочку в таблице или через ПКМ;
- раздел **Избранное** собирает такие записи в одном месте.

### Корзина

- обычное удаление переносит запись в корзину;
- в корзине можно восстановить запись;
- можно удалить запись навсегда;
- можно очистить корзину целиком.

## Вложения

Вложения уже поддерживаются в редакторе записи.

Что можно делать:

- добавлять вложения;
- открывать вложения;
- сохранять их в другое место;
- копировать имена файлов;
- удалять вложения.

Нормальное поведение:

- вложения сохраняются вместе с записью;
- если вы отменили редактирование записи, новые вложения из этой сессии не должны сохраниться;
- если внешний просмотрщик держит файл занятым, некоторые операции могут временно не сработать.

---

## Генератор паролей

Генератор паролей можно открыть:

- с верхней панели главного окна;
- из окна редактирования записи рядом с полем пароля.

Он нужен для быстрого создания нового пароля без ручного ввода.

---

## Блокировка приложения

В приложении уже работает блокировка.

Где находится:

- **Меню -> Блокировать**;
- в некоторых сценариях также доступны связанные действия разблокировки.

Нормальное поведение:

- после блокировки для доступа снова нужен мастер-пароль;
- во время редактирования приложение старается сохранить контекст;
- если были несохраненные изменения, после блокировки и возврата могут потребоваться подтверждение или повторная проверка состояния формы.
