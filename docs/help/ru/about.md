## Что такое PassNotes Desktop <a id="about"></a>

PassNotes Desktop — локальное WPF/.NET приложение для хранения паролей и заметок в **зашифрованном хранилище (vault)** с поддержкой папок, записей и вложений.

Цель — удобный офлайн‑менеджер данных, который хранит информацию на вашем компьютере и управляется через понятный UI.

## Статус <a id="status"></a>

Проект находится в активной разработке (**beta**). Функциональность и поведение могут уточняться; перед важными изменениями данных рекомендуется иметь актуальные резервные копии.

## Ключевые сущности <a id="concepts"></a>

- **Vault** — основное зашифрованное хранилище.
- **Папки** — структура для организации записей.
- **Записи** — элементы с полями (например, логин/пароль/комментарий) и опциональными вложениями.
- **Экспорт/импорт** — через файл **`.pnexp`** (зашифрованный формат).
- **Вложения** — файлы, привязанные к записи и хранящиеся в зашифрованном виде.

## Приватность и безопасность <a id="privacy"></a>

- PassNotes Desktop ориентирован на локальное хранение данных (без облачной синхронизации “из коробки”).
- **Мастер‑пароль не восстанавливается**: если он утерян, доступ к содержимому vault будет невозможен.
- Экспорт/импорт выполняется только в **зашифрованном** формате **`.pnexp`**.
