PassNotes Desktop {{VERSION}} для Windows

Текст публикации:
Подготовил новую сборку PassNotes Desktop {{VERSION}}.

PassNotes Desktop — локальное desktop-приложение для хранения заметок, паролей, комментариев и вложений в зашифрованном vault-хранилище.

Что внутри:
- {{INSTALLER_NAME}} — основной рекомендуемый вариант для большинства пользователей Windows
- {{PORTABLE_NAME}} — portable-версия без установки
- INSTALL_RU.txt — короткая инструкция по установке и запуску
- SHA256SUMS.txt — контрольные суммы для проверки файлов

Важно:
- текущая сборка пока без code signing, поэтому Windows SmartScreen может показать предупреждение при первом запуске installer
- пользовательские данные хранятся в %APPDATA%\PassNotes
- uninstall установленной версии не удаляет данные автоматически
- portable-версию нужно сначала распаковать, а не запускать прямо из архива

Если нужен самый простой вариант, выбирайте installer.
Portable оставлен как альтернативный вариант.
