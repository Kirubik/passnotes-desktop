Дополнительные файлы:

Рекомендуемый порядок действий:
1. Загрузить {{INSTALLER_NAME}} как основной файл публикации.
2. Загрузить {{PORTABLE_NAME}} как альтернативный вариант.
3. Добавить INSTALL_RU.txt и SHA256SUMS.txt в тот же набор файлов.
4. Вставить текст из BOOSTY_POST_RU.txt в описание публикации.
5. Отдельно не забыть оставить предупреждение про SmartScreen:
   текущая сборка без code signing, поэтому Windows может показать предупреждение при первом запуске installer.

Что важно явно донести пользователю:
- installer — основной и рекомендуемый вариант;
- portable — запасной вариант без установки;
- данные пользователя лежат в %APPDATA%\PassNotes;
- uninstall не удаляет пользовательские данные автоматически.
