PassNotes Desktop {{VERSION}}

Состав пакета:
- {{INSTALLER_NAME}} — рекомендуемый вариант для большинства пользователей Windows.
- {{PORTABLE_NAME}} — portable-версия без установки.
- SHA256SUMS.txt — контрольные суммы для проверки файлов.

Как установить:
1. Запустите {{INSTALLER_NAME}}.
2. Если Windows SmartScreen покажет предупреждение, это ожидаемо: текущая сборка пока без code signing.
3. Завершите установку и запустите PassNotes Desktop через ярлык в меню Пуск или на рабочем столе.

Как использовать portable-версию:
1. Распакуйте {{PORTABLE_NAME}} в отдельную папку.
2. Не запускайте приложение прямо из архива.
3. Запускайте PassNotes.exe из распакованной папки и не разносите файлы portable-пакета по разным местам.

Данные пользователя:
- Настройки и vault хранятся в %APPDATA%\PassNotes.
- Uninstall установленной версии не удаляет данные автоматически.

Проверка файлов:
- Для проверки целостности сравните SHA256 ваших файлов с SHA256SUMS.txt.
